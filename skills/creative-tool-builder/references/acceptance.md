# 验收与交付

按用户实际要求选择测试，记录结果，不把未检查的项目说成已通过。

1. 设计：核对目标画板的比例、位置、颜色、素材、文本、变体及 RTL。
2. 编辑：空值、典型值、长文案、图片与透明图；字段切换或折叠不丢失内容，删除或重置有合理反馈。
3. 预览：手机和桌面无意外横向溢出；键盘可操作、控件有标签、焦点可见，错误与导出进度可感知。
4. 导出：实际下载并检查图片像素尺寸、内容、透明度、文件名；批量包检查数量、语言、目录和代表性文件。检查预览与输出一致。
5. 构建：运行仓库要求的构建和必要测试，说明失败及影响。检查示例素材授权，排除密钥、用户数据与部署配置。
6. 发布：仅在用户授权且目标明确时进行；区分私有仓库和网站访问范围。核验实际线上地址及部署状态，不把预览地址称为正式地址。
