# 需求核对

按任务需要获取信息，不把整份表机械地追问给用户；已有设计稿和项目可以直接提供答案。

- 目标：使用者、要解决的问题、期望交付。
- 设计：具体 Figma 节点、页面/画板范围、尺寸、授权素材与品牌规范。
- 编辑：字段、默认值、必填、图片比例/裁切、变体、数据来源；刷新后是否需要保留。
- 本地化：语言清单、每个字段的权威文案、长文本及阿拉伯语/波斯语等 RTL 排版。
- 预览/导出：尺寸和比例、主题或设备变体、PNG/JPG、像素密度、单张/批量、ZIP 层级与命名示例。
- 发布：是否要求网站登录、仓库及部署归属、谁能看、是否涉及敏感信息、验收人。

示例需求：运营选择一个至三个标的，替换图标，预览选定语言，并下载 1200×1200 PNG 或全部语言 ZIP。此例仅作为沟通示例，不应默认套用。
