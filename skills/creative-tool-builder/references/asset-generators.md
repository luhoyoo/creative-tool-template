# 图片与营销素材生成器

## 画布与状态

- 识别设计画板的实际尺寸，以同一个内容模型驱动编辑控件、预览和导出；预览缩放不应改变导出像素尺寸。
- 显式处理长标题、可编辑文案的换行、图片加载及空值。不要用静态设计截图冒充可编辑海报。
- 图片上传仅在需要时添加；说明透明图底色、圆形裁切、缩放范围与默认素材。不要擅自将用户图片上传到外部服务。
- 多语言必须使用提供的权威文案和实际语言清单，不用英文占位假装翻译；RTL 除了文本方向，还要检查图标顺序和画面布局。
- 区分产品页面深色主题与用户要求的海报主题。尊重用户的 Figma 素材、字体、比例和已批准的视觉设计。

## 导出

- 使用现有项目的导出方式；若使用 DOM 转 PNG，检查字体与图片加载、跨域、透明背景、缩放、输出像素及文件名。跨语言批量导出时确保每张均使用对应语言的最新状态，完成或失败后恢复预览。
- 批量运行期间防止中途修改造成混合结果；报告进度和可操作的失败原因。若 ZIP 有目录或命名约定，检查压缩包实际内容。
- 给用户的长文本、复杂脚本和不同图标都要在预览与实际导出中检查；自动缩字号不能意外改变用户指定的对齐方式。
- 示例中提供的 Logo、背景和多语言内容只供模板演示，需确认适用范围和权限，不应把示例文案称作已由业务方审核。
