# 交付验收清单

- [ ] 页面与目标设计稿的版式、文案、素材和数量一致；示例内容已替换。
- [ ] 所有可编辑字段可用，必填项、空值和长内容有清楚反馈。
- [ ] 上传、透明图、裁切与缩放符合需求；刷新后的数据保存行为已说明。
- [ ] 每种尺寸、主题及语言在预览和实际导出中均正确；必要时核对 RTL 排版。
- [ ] PNG 实际像素尺寸正确；ZIP 包含要求的文件、目录及文件名。
- [ ] 手机、平板、桌面可用；键盘可操作，焦点及错误提示可见。
- [ ] `npm run build` 成功；核对资源授权及无密钥、个人数据、`.env` 或本地部署配置入库。
- [ ] 网站访问范围、仓库可见性与公司要求一致；发布前确认负责人和部署目标。
