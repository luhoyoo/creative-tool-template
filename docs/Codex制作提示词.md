# Codex 制作提示词

复制下面内容，填入需求表和设计稿链接，在新项目中发给 Codex。

```text
请基于当前创意小工具模板实现一个新的工具。保留适用的工作台、预览与导出能力；不适用的示例内容请按需求替换。

【需求填写表】
（粘贴已填写的需求表）

【Figma 设计稿】
（粘贴具体画板链接）

请先检查项目及设计稿，然后实现交互、实时预览和导出。验证长文案、多语言、图片上传、移动端和键盘操作中与本工具相关的部分；检查导出的实际文件和命名。运行构建并告诉我预览地址、已验证内容及未完成事项。

先提供可审阅的本地版本；是否创建仓库、连接服务及上线，按我另行给出的指示执行。
```
