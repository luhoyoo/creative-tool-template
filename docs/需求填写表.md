# 小工具需求填写表

复制本文件，为每个新工具填写一份；不适用的项目写“不需要”，不确定的写“待确认”。

## 目标

- 工具名称：
- 使用人群、使用场景：
- 要解决的问题、期望结果：
- 是否涉及客户信息、内部数据或受限素材：

## 设计与内容

- Figma 链接及画板节点：
- 页面或画板数量、优先还原范围：
- 品牌素材来源及使用权限：
- 可编辑字段、必填项和默认值：
- 图片上传要求、裁切比例及透明图处理：
- 支持语言、文案来源、是否有阿拉伯语或波斯语：
- 超长文字、缺失素材、空值如何处理：

## 预览与导出

- 海报或弹窗尺寸、版本及主题：
- 是否需要实时预览：
- 导出格式、图片尺寸和像素密度：
- 批量导出内容、ZIP 目录和文件命名示例：
- 需要重点验证的边界情况：

## 交付与发布

- 仓库归属及可见性：
- 网站访问范围、是否需要登录：
- 部署账户、域名或独立项目要求：
- 验收人及验收标准：
- 其他约束：
